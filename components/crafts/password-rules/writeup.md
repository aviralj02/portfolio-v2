A password field that crosses off its own rules as you type.

The rules sit under the field as one sentence: use 8+ characters, an uppercase letter, a number and a symbol. Meet one and a green line strikes through that phrase. It holds for a beat, dimmed, so you actually see it get ticked off, and only then closes up while the rest of the sentence slides together and re-joins itself.

Break a rule again and its phrase opens back up in place. Once nothing is left, the sentence gives way to "Good to go" and the password itself turns green.

The checks live in one schema. Each rule reports its own name when it fails, so the list of failures is exactly the sentence that's left to show.
